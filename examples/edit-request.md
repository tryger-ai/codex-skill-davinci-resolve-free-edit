# 編集依頼例

以下のパスは例です。実在する素材と希望の保存先へ置き換えてください。

```text
$davinci-resolve-free-edit を使って編集してください。

素材A：C:\Media\sample-a.mp4
素材B：C:\Media\sample-b.mp4
目的：会話の自然な流れを優先した短い縦動画
優先順位：セリフのつながり → 表情 → テンポ → 尺

1. Aの1〜3秒を映像・音声とも使用
2. Aの3〜6秒の音声を続けながら、Bの4〜7秒の映像を使用
時間は素材先頭からの秒数。終了時刻は含まない。
セリフの順番変更・省略はしない。細かなつなぎ方は任せる。
口の動きと音声が合わない場合は、確認できた差を報告して。

テロップ：音声に沿う日本語と英訳。参考プロジェクトの書式を確認して再設定。
参考プロジェクト：ここにプロジェクト名とタイムライン名を指定
保存先：C:\Media\Exports
ファイル名：sample-edit.mp4
別名の作業タイムラインを作り、保存・書き出しまで行ってください。
```

修正は「完成動画の時刻／変更内容／理由／今回だけか共通ルールか」で伝えます。共通ルールの保存は明示的に依頼してください。参考にする書式や好みは案件ごとに指定し、このスキルに特定作品の設定を固定しません。
